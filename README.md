# Website-Tection-Scanner
Just a basic website scanning tool for web application testing

*****ONLY USE THIS TOOL FOR WEBSITES YOU HAVE CONTRACTS WITH TO DO WEB APPLICATION TESTING ON!!!!!!!


This code provides a basic security scanner with the following features:

1. **Spidering**:
   - Crawls the website to discover pages
   - Follows links within the same domain
   - Discovers forms for testing

2. **Vulnerability Scanning**:
   - SQL Injection testing
   - Cross-Site Scripting (XSS) testing
   - Directory Traversal testing

3. **Reporting**:
   - Generates a text report with findings
   - Lists vulnerable URLs and payloads
